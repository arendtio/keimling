# Feature: Agent overview

## REQ-AO-1 One page for every agent

- **Statement:** Keimling shall offer an agent overview that lists each agent with its definition and whether it is running, on a call, paused, waiting, or idle. Opening an agent goes to its chat. The page can be focused and made fullscreen like the other side pages.
- **Origin:** User, 2026-11-08 (paraphrase: a dedicated overview of who is running, waiting on an event, and which definition they use; click through to the main channel; open it as focus or fullscreen).
- **Fit criterion:** With several agents, the Agents page shows a grid of blocks, one per agent, each at most 400 pixels wide. A block shows the name, definition, and phase. A waiting agent says whether it waits for a message, an alarm, or a watch. Choosing one opens that agent's chat. Focus and Fullscreen enlarge the page.
- **Priority:** shall
- **Status:** confirmed
