# User stories: Skills

## US-32 — Leave unused skills out of the prompt

**As** a user, **I want** to turn individual skills on or off, **so that** skills from another harness do not fill the prompt of a local model.

**Acceptance:** traces REQ-SK-1.

## US-33 — Decide how a new skill starts

**As** a user, **I want** to choose whether a newly discovered skill starts on or off, **so that** I can enable them by hand now and include them automatically later.

**Acceptance:** traces REQ-SK-2.
